# security-automation-scanner # Security Automation Port Scanner

## Overview
This project is a Python-based security automation tool designed to perform basic network scanning. It identifies open ports on a target system and attempts to gather service information (banner grabbing).

## Features
- Scans common ports
- Identifies open ports
- Performs basic banner grabbing
- Simple and lightweight

## Technologies Used
- Python 3
- Socket Library
